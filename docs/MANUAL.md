# 사용 매뉴얼

임장 입지분석 가이드(`imjang-location-guide`)를 처음 쓰는 분을 위한 안내서입니다.

## 1. 이 스킬이 하는 일, 하지 않는 일

**하는 일**
- 단지 주변 반경 1km의 지하철·마트·시장·공원·초등학교·주변 단지를 조회해 정리합니다.
- 거리는 항상 "미터 + 걸어서 몇 분"으로 씁니다.
- 지하철 개통 같은 호재는 웹에서 따로 확인하고 신뢰도 등급을 붙입니다.
- 현장에 가져갈 체크리스트가 들어간 HTML 보고서와 지도를 만듭니다.

**하지 않는 일**
- 시세·실거래가·대출 분석
- 특정 단지를 사라/사지 말라는 권유
- 학교 우열, 치안, 소음 수치 단정 (데이터가 없어 현장 확인 항목으로 넘깁니다)

## 2. 준비물

1. **ipzitalk(입지톡) MCP 연결.** 입지 요소는 이 데이터만 씁니다. 없으면 동작하지 않습니다. 다른 분이 이 스킬을 쓰려면 ipzitalk 접근 권한이 따로 필요합니다.
2. **웹 검색.** 호재 조사에만 씁니다.
3. **코드 실행·파일 생성.** HTML 보고서를 파일로 받으려면 필요합니다.

## 3. 설치

### Claude 앱 (Pro / Max / Team / Enterprise)

1. 레포의 `skills/imjang-location-guide` 폴더를 ZIP으로 압축합니다. ZIP을 열었을 때 `imjang-location-guide` 폴더가 최상위에 보여야 합니다.
2. 설정 > Capabilities에서 **코드 실행 및 파일 생성**을 켭니다.
3. 같은 화면 아래 **Skills** 섹션에서 **Upload skill**을 눌러 ZIP을 올립니다.
4. Skills 목록에서 켜져 있는지 확인합니다.

Team·Enterprise는 관리자가 조직 설정(Admin settings > Capabilities)에서 Skills를 켜 둬야 합니다. 직접 올린 스킬은 본인 계정에서만 보이고, 다른 사람과 바로 공유되지는 않습니다.

업로드가 실패하는 흔한 이유 (공식 안내 기준)
- ZIP 용량 초과
- 폴더 이름과 스킬 이름 불일치 (이 스킬은 둘 다 `imjang-location-guide`)
- `SKILL.md` 누락
- 이름·설명에 허용되지 않는 문자

### Claude Code

```bash
mkdir -p ~/.claude/skills
cp -r skills/imjang-location-guide ~/.claude/skills/
```

- `~/.claude/skills/`는 이 컴퓨터의 모든 프로젝트에서 쓰이는 개인용 위치입니다.
- 팀과 같이 쓰려면 프로젝트 안 `.claude/skills/`에 폴더를 두고 커밋합니다.
- 스킬 파일을 고치면 세션 중에도 반영됩니다.
- Claude Code에서도 ipzitalk MCP를 연결해야 합니다.

## 4. 첫 실행

아래처럼 말하면 됩니다. 단지명이 하나로 특정되면 되묻지 않고 바로 시작합니다.

```
래미안안양메가트리아 임장 준비해줘
평촌어바인퍼스트 입지 분석해줘
이 동네 살기 어때: 범계역 근처 아파트
```

Claude Code에서는 슬래시 명령도 됩니다.

```
/imjang-location-guide 평촌어바인퍼스트
```

이름은 `/imjang`이 아니라 `/imjang-location-guide`입니다.

동네나 역 이름만 주면 후보 단지를 먼저 보여 주고 고르게 합니다. 한 번에 1~3곳까지 넣을 수 있고, 4곳 이상이면 3곳씩 나눠 진행합니다.

## 5. 내 상황 알려 주기

말하지 않으면 '일반 실거주'로 가정하고, 그 가정을 요약과 보고서 상단에 한 줄로 밝힙니다. 아래 중 해당하는 걸 말하면 '내 상황 기준 읽기'에 반영됩니다. 여러 개도 됩니다.

| 이렇게 말하세요 | 먼저 보는 것 | 흔한 함정 |
|---|---|---|
| 첫 집·신혼·전월세 | 출퇴근 역까지 거리, 마트·편의점·배달, 밤길 | 지도상 가까워도 실제 길이 멀거나 가파름 |
| 학령기 자녀 | 초등학교 거리·통학로, 공원·놀이터, 학원가 | 학교가 가깝다고 배정되는 건 아님 (학구도 확인) |
| 자녀 독립·은퇴 준비 | 병원·약국, 마트·시장 도보, 평지 여부, 조용함 | 지도에 없는 경사·계단 |
| 투자 관점 | 호재 일정의 불확실성, 주변 공급, 임차 수요 | 호재는 밀리거나 번복될 수 있음 |

예: `평촌어바인퍼스트 입지 분석, 학령기 자녀 기준으로`

## 6. 결과 읽는 법

**채팅 요약이 먼저 나옵니다.** 표(구분·내용·직선거리·도보 추정), 유리한 점과 주의할 점, 호재, 데이터 한계 순서입니다. 그 뒤에 HTML 보고서가 만들어집니다.

**표기 규칙**

| 표기 | 뜻 |
|---|---|
| 참고용 | 반경 1km 밖 항목. 핵심 지표에는 포함하지 않음 |
| 1km 내 0 | 반경 안에 해당 시설이 조회되지 않음 |
| 슈퍼마켓 | 대형마트 분류에 잡혔지만 실제로는 슈퍼마켓 |
| 확인되지 않음 / 조회 실패 | 데이터가 없거나 조회가 안 됨. 추정해서 채우지 않음 |
| 🟢 | 호재: 착공·확정 |
| 🟡 | 호재: 계획·협의 중 |
| ⚠️ | 호재: 보도만 있거나 일정이 번복된 이력 |

**도보 시간은 직선거리를 분속 75m로 나눈 추정치**입니다. 경사·신호·우회가 있으면 더 걸립니다. 1km를 넘으면 "도보 15분+"로 씁니다. 차량 시간은 1km당 대략 3~4분으로 잡은 '대략'치입니다.

**초품아**는 초등학교를 큰길 건너지 않고 갈 수 있는 단지를 말합니다. 단지 부지 안에 학교가 없으면 '초품아 아님'으로 씁니다. 학교가 가깝더라도 배정은 교육청 학구도에서 따로 확인해야 합니다.

**호재 연도는 자료마다 다를 수 있습니다.** 이 경우 최신 자료를 쓰되 "자료 간 편차·순연 이력"을 같이 적습니다. 확정 일정으로 믿지 마세요.

**지도 링크는 약 7일 뒤 만료**됩니다. 보고서에 만료일이 적혀 있고, 만료되면 다시 만들어 달라고 하면 됩니다.

## 7. 임장 당일 쓰는 법

1. 보고서 하단의 **임장 체크리스트**를 인쇄하거나 폰으로 엽니다. 인쇄 화면에서는 지도가 숨겨지고 지도 링크 텍스트가 보입니다.
2. 데이터에서 나온 주의점(역이 멀다, 학교가 건너편이다)은 해당 항목이 강조되어 있습니다. 그 항목부터 확인하세요.
3. 시간대를 달리해 방문하세요. 평일 아침 출근 시간, 주말 낮, 평일 밤.
4. 지하철역·마트·초등학교까지 직접 걸어서 시간을 재 보세요. 경사·계단·횡단보도·큰길 여부도 같이 봅니다.
5. 중개사·관리사무소 질문 목록을 챙기세요. 관리비, 하자·누수 이력, 층간소음, 재건축·정비 계획, 학구 배정, 주차 대수.

## 8. 2~3곳 비교

여러 곳을 한 번에 넣으면 보고서 맨 위에 비교표가 생깁니다.

```
래미안안양메가트리아와 평촌어바인퍼스트 비교해줘, 학령기 자녀 기준으로
```

우열을 매기지 않습니다. "이 상황에는 A단지가 유리한 항목" 형태로 보여 줍니다. 단지마다 지도가 따로 생기고, 체크리스트는 마지막에 한 번만 나옵니다.

## 9. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 데이터가 하나도 안 나옴 | ipzitalk MCP가 연결돼 있는지, 승인 요청이 거절되지 않았는지 |
| 도구 승인 요청이 거절됨 | 같은 요청을 다시 보내세요. 끝내 안 되면 해당 항목은 '조회 실패'로 표시됩니다 |
| 지하철역이 '1km 내 0'으로 나옴 | 정상일 수 있음. 반경 밖 최근접역이 '참고용'으로 따로 표시됩니다 |
| 공원·시장 결과에 엉뚱한 곳이 섞임 | 키워드 검색 특성상 충전소·음식점이 섞일 수 있어 업종 분류로 걸러냅니다. 그래도 이상하면 해당 항목을 짚어 주세요 |
| 후보 단지가 여러 개로 나옴 | 질문에 하나 고르면 됩니다. 정확한 단지명이나 도로명 주소를 주면 줄어듭니다 |
| 지도가 안 보임 | 링크 만료(약 7일)일 수 있음. 지도 재발급을 요청하세요 |
| HTML 파일을 못 찾겠음 | 파일 생성이 켜져 있는지 확인하고, 저장 위치를 알려 달라고 하세요. 저장 경로는 쓰는 환경에 따라 다를 수 있습니다 |
| 앱 업로드가 실패함 | 3장의 실패 원인 목록 확인 |
| 슬래시 명령이 안 됨 | 이름은 `/imjang-location-guide` |

## 10. 한계와 주의

- 시간은 직선거리 기반 추정이고, 실제 길은 다를 수 있습니다.
- 이 보고서에는 시세·실거래가·대출 정보가 없습니다. 아래에서 직접 확인하세요.
  - 국토교통부 실거래가 공개시스템
  - 교육청 학구도 안내서비스
  - 해당 지자체 도시계획 공고
- 학교 수준, 치안, 소음 수치는 데이터가 없어 단정하지 않고 현장 확인으로 넘깁니다.
- 호재는 일정이 밀리거나 번복될 수 있습니다.
- 정보 제공 목적이며 투자·계약 조언이 아닙니다.

## 11. 업데이트

3. Claude 앱은 새 ZIP을 다시 올립니다.
